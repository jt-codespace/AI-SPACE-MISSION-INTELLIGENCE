# 🚀 AI Space Mission Intelligence Dashboard

An interactive AI-powered dashboard for analyzing historical space missions, visualizing launch trends, and predicting mission outcomes using Machine Learning.

🌐 **Live Demo:** https://ai-space-mission-intelligence-f7hvuhysshzqyfkdj4j5ax.streamlit.app/

---

## 📌 Features

- 🚀 Launch Trend Analysis
- 🌍 Country-wise Mission Analysis
- 🏢 Top Space Organizations
- 📊 Mission Success Rate Visualization
- 💰 Mission Cost Analysis
- 🤖 AI Mission Success Prediction
- 📥 Download Filtered Dataset

---

## 🛠️ Tech Stack

- Python
- Pandas & NumPy
- Plotly
- Scikit-learn
- Streamlit
- Git & GitHub
